# ✅ Gerenciador de Tarefas em Python

Aplicação simples de terminal para organização de tarefas.

## Objetivo

Praticar operações de cadastro, listagem e alteração de estado em uma estrutura de dados simples.

## O que demonstra

- Listas e dicionários
- Funções
- Condicionais e loops
- Organização de fluxo
- Regras simples de estado

## Como explicar em entrevista

> "Usei um gerenciador de tarefas para praticar CRUD e controle de estado em Python. O aprendizado principal foi organizar ações diferentes sobre a mesma coleção de dados."

## Papel no portfólio

Projeto de fundamentos, mantido como registro de evolução.
